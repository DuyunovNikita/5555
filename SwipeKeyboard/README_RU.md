# Swipe Keyboard — прототип для Windows 10/11 x64

## Сборка
Проект использует .NET 8 WPF. На Windows с установленным .NET 8 SDK выполните:

```powershell
dotnet publish .\SwipeKeyboard\SwipeKeyboard\SwipeKeyboard.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

Установщик собирается через Inno Setup 6:
```powershell
ISCC.exe .\SwipeKeyboard\installer.iss
```

GitHub Actions запускает сборку автоматически после изменения исходников в main. Готовый установщик публикуется как artifact `SwipeKeyboard-Setup-win-x64`.

## Уже есть
- Русская и английская раскладки.
- Ввод нажатием и базовая запись траектории свайпа.
- Ввод Unicode-символов, в том числе кириллицы.
- Переключение тёмного/светлого оформления.
- Перемещение окна, изменение размера и режим поверх окон.
- Горячая клавиша Ctrl + Shift + Space.
- Скрипт Inno Setup с ярлыком и опциональным автозапуском.

## Ограничения прототипа
Это ранняя техническая версия, не полноценная замена SwiftKey. Текущий свайп просто склеивает пройденные буквы; нет языковой модели, словаря, контекстного предсказания, ранжирования вариантов, коррекции опечаток и автоматической заглавной буквы. Цифровой/символьный режим, Shift и Ctrl пока требуют полноценной реализации. Перед повседневным использованием необходимо проверить поведение ввода в разных приложениях Windows.
